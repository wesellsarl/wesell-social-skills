# wesell-social-skills

Sélection de 27 skills issues de [social-media-skills/skills](https://github.com/social-media-skills/skills) (MIT, commit `f28cef2`), adaptée à We Sell.

## Installation (Claude Code)

```
/plugin marketplace add wesellsarl/wesell-social-skills
/plugin install wesell-social-skills@wesell
```

Le dépôt étant privé, Claude Code doit avoir accès à GitHub avec ton compte (`gh auth login`).

## Ce qui a changé par rapport à l'original

- **Sélection** : 27 skills sur 106. Retirées : publication/planification (`scheduling-and-queue`, `content-calendar`), analytique, outils IA payants, plateformes non utilisées.
- **Consigne prioritaire** ajoutée en tête de chaque `SKILL.md` : publication et statistiques via Metricool ou Blotato (jamais WoopSocial), traitement direct quand une skill renvoie vers une skill absente, priorité aux skills `agents-marketing-contenu` et `wesell-video-tiktok` pour le contenu de marque.
- Le reste du texte est inchangé ; aucune variable d'environnement n'est nécessaire.
